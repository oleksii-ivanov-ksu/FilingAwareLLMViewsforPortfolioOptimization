# Offline signal and risk diagnostics — 2026-11-16

Fixed before inspecting the new diagnostic outputs, but post hoc to the known historical results. No LLM calls, parameter search, or change to frozen data. Editorial V2 only; architecture project untouched.

1. Quarterly cross-sectional IC: latest recorded filing view available at quarter end, maximum age 120 calendar days, across each fixed 50-stock group. Forward outcome is price return from the last trading close on/before that date to the last trading close on/before next quarter end. Require the full outcome through 2025-12-31. This is a rebalance-date diagnostic of available views, not a fresh-filing event study. Exclude missing endpoint prices. Spearman average ranks; at least 10 stocks and nonconstant views. Report all/low/medium/high separately; confidence groups may have insufficient observations. Hit rate excludes zero views, reports absolute direction and direction relative to the contemporaneous group equal-weight outcome; always-positive hit baseline included. Top-minus-bottom quintiles use average percentile ranks >=.8 and <=.2; require >=5 distinct values and >=10 stocks, never break ties using future returns. Equal-weight date summaries; HAC Bartlett lag 4 quarters, finite-sample correction, normal-reference inference; primary IC Holm correction across the two groups. No claim of clean temporal out-of-sample validation.

2. Offline factor analysis: cached Kenneth French daily market, SMB, HML, momentum and RF; FF5+momentum sensitivity. Daily net returns, exact inner date match with omissions reported. OLS with intercept; HAC Bartlett lag21 days, finite-sample correction. Alpha = 252*daily intercept. For return differences do not subtract RF again. Real, unconditional prior tilt, EW, both new controls, ensemble-mean full-reassignment returns and all individual full-reassignment seeds. Main contrast real minus prior; Holm across both groups. Ensemble mean is a diagnostic, not median-seed performance.

3. No-LLM risk tilts: positive tilt_strength=1, same clip-then-normalize allocator .005/.10, quarterly dates, drift, transaction costs .001*L1 and original history/fallback semantics. Beta is trailing 252-day covariance with the within-group equal-weight daily return divided by its variance; volatility is trailing 252-day standard deviation. Neither uses LLM eligibility. Prior tilt is computed unconditionally from 2.5*annualized shrunk covariance*EW. Compare with frozen real/EW and saved prior; validate a new arm with shared engine. No optimization of direction/window/strength.

4. Report performance for 2006–2012, 2013–2019, 2020–2025 with actual starts and 756-day rolling arithmetic Sharpe. Keep 2% RF in main performance for comparability; also report realized French RF Sharpe. Paired 21-day block bootstrap for real minus risk tilts, 10,000 draws; these are post-hoc conditional intervals.

5. Horizon diagnostic: quarterly covariance/prior (annual values/4), unchanged quarterly Q and Omega; compare to annual covariance/prior with Q*4 and Omega*4. Posterior scaling should leave z-score tilts unchanged. Preserve unconverted main historical results, explicitly label the converted result an assumed-horizon sensitivity rather than an estimated forecast calibration.

6. Audit: recompute CAGR, volatility, arithmetic Sharpe, drawdown including initial wealth=1; identify exact EW/MVO drawdowns; inspect dates, counts and model-run accounting. Persist per-date IC, input/outcome panel, targets, daily returns, regressions, hashes and validation. No changes to historical model leakage or survivor-selected universe are implied by these checks.

Implementation checks caught two issues before portfolio outcomes were inspected: quarterly schedules use business quarter ends, so outcomes now use the next calendar quarter end; and the annual representation equivalent to Sigma/4, prior/4, Q, Omega at unchanged tau uses 4Q/4Omega, not 4Q/16Omega. The earlier 4Q/16Omega sensitivity is a distinct uncertainty assumption, retained separately. Failed assertion outputs are archived.
