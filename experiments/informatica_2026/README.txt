INFORMATICA REVISION — OFFLINE REPRODUCTION PACKAGE

See ../../README.md for the current article title, results, data scope and commands.
Includes 300 pilot, 1,194 portfolio-masking and 1,791 summary-ablation minimal
response records, saved weights and derived portfolio returns. Full prompts,
narrative responses and raw market inputs are not included.

Run with Python 3.11+ and requirements.txt:
  python verify_and_reproduce.py

The verifier recomputes analyses from saved outputs in a temporary copy. It
makes no API calls and does not rerun model inference or portfolio simulation.
No DOI has been assigned; cite this repository and the relevant commit.
