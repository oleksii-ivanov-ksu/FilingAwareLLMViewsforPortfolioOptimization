`x-ai/grok-4.3`, прямой endpoint xAI (каталог обозначает версию 20260430).
Это не повтор исторического Grok 4.1 Fast. Доступность и тарифы сохранены
в `grok43_endpoints_20261116.json`. Returned model/provider архивируются.

Входы: `pilot_inputs_reviewed_v1`, исходная выборка `pilot_preparation_v3`.
50 разных компаний, два условия, три независимых запроса на условие.
Порядок — уже сохранённая случайная перестановка 300 заданий. Без общей истории,

остальные настройки модели — defaults провайдера, не исторические настройки.
Идентификатор публичной модели не гарантирует неизменность серверных весов.

Обезличивание проверено агентом, не независимым экспертом: ещё 295 замен
в 44 документах. Числа, даты, system prompt и числовая часть входа сохранены.

может убирать экономически полезный контекст. Исходная extraction не меняется.

## Исходы и анализ

Единица анализа — документ (50 уникальных компаний), не отдельный запрос.
Основной показатель: среднее абсолютное изменение среднего view_bps между
условиями. Дополнительно: среднее подписанное изменение (masked − original),
доля изменения знака среднего (ноль — отдельная категория), Spearman средних,
частоты confidence. Ранги на неодновременных документах — диагностика, не портфель.
Для контроля stochastic variability вычислить среднюю абсолютную разницу
трёх пар original-original и anonymized-anonymized, а также девяти межусловных
пар внутри каждого документа. Показать cross-distance минус среднее двух
within-distance. Это диагностическая мера, не несмещённая оценка causal effect.

95% percentile bootstrap CI: 10 000 перевыборок документов, seed 20261116.
CI условны для этой стратифицированной диагностической выборки с намеренным
перепредставлением нейтральных views; среднее не переносить на весь корпус.
Основной анализ включает случаи с тремя валидными ответами в обоих условиях;
число исключённых и причины публикуются. Не трактовать незначимость как эквивалентность.
Нет заранее обоснованного equivalence margin и подтверждающего теста equivalence.

Валидный ответ: finish_reason=stop, ровно три поля, целое view_bps в [-300,300],
confidence high/medium/low, непустая строка reasoning. Без обрезки значений,
исправления JSON, подстановки defaults или повторов неудачного по смыслу ответа.
Ошибки формата, пустые/обрезанные ответы и отказы сохраняются отдельно.
Не более двух HTTP-попыток на задание, повтор только transport/429/5xx;
ошибки авторизации/баланса останавливают весь запуск. Все попытки архивируются.
После неопределённого обрыва процесса начатое задание не повторять автоматически.

Локальный запуск ограничен 300 заданиями; полный корпус не запускается.
Лимит расходов $10 по reported usage; при отсутствии usage cost остановка.
До запуска сохраняются config, protocol, schedule и код с SHA-256.
После запуска публикуются все исходы и стоимость. Новые original ответы являются
контролем; исторические views не используются как единственная контрольная группа.
